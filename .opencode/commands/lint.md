Run code quality checks on the Cronômetro project.

Execute `npm run lint` to run ESLint, then `npm run format` to run Prettier.

Report any linting errors or formatting issues. If fixes are needed, apply `npm run lint:fix` and `npm run format`.

Verify all files pass linting before reporting completion.
