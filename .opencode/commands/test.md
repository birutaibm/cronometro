Run the full test suite for the Cronômetro project.

Execute `npm run test` which runs both unit tests (Jest) and integration tests (Playwright).

Report the results. If tests fail, analyze the error output and suggest fixes.

For unit tests only, use `npm run test:unit`.
For integration tests only, use `npm run test:integration`.
